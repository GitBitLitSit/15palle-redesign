# 15 Palle, redesign

Design preview for the website of Circolo sportivo 15 Palle, the billiard club and bar in Via Bruno Buozzi 12, Bolzano.
It is a static Next.js site: the member area is a demo and talks to no backend.

```bash
npm install
npm run dev     # http://localhost:3001
npm run build   # static export in out/
```

Every push to `main` is built and published to GitHub Pages by `.github/workflows/pages.yml`.
